# Setup Guide

## Repository Location

This project is maintained inside the ROS 2 workspace root on the host machine.

Command:

cd ~/ros2_ws

## GitHub Remote

Repository:

https://github.com/alpkarakoc/autonomous_robotics_lab.git

## Ignored Folders

The following generated ROS 2 folders are intentionally ignored:

- build/
- install/
- log/

## Standard Push Workflow

1. Check status.
2. Stage only source, documentation, and configuration files.
3. Commit with a meaningful message.
4. Push to GitHub.
