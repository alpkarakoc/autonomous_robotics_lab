# Requirements

## Functional Requirements

FR-1: The project shall maintain a ROS 2 workspace under version control.
FR-2: The project shall ignore generated ROS 2 build artifacts.
FR-3: The project shall document setup steps for future maintainers.
FR-4: The project shall support an Autoware simulation/lab workflow.
FR-5: The project shall keep source files separate from generated build outputs.

## Non-Functional Requirements

NFR-1: The repository shall be reproducible from source files.
NFR-2: The repository shall be maintainable through a clear folder structure.
NFR-3: The repository shall be traceable through meaningful Git commits.
NFR-4: The repository shall avoid committing generated or machine-specific files.
NFR-5: The project shall provide enough documentation for another developer to understand the setup.
