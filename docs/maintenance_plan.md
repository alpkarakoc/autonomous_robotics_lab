# Maintenance Plan

## Version Control Rules

1. Commit only source code, documentation, and configuration files.
2. Do not commit ROS 2 generated folders: build, install, and log.
3. Use clear commit messages.
4. Review git status before every commit.
5. Keep GitHub as the remote backup and collaboration point.

## Recommended Commit Style

- docs: update setup guide
- chore: initialize repository structure
- feat: add ROS 2 package
- fix: correct launch configuration
