# Quality Attributes

## Maintainability

The project uses a clear folder structure and excludes generated ROS 2 build artifacts from Git.

## Reproducibility

Setup steps are documented so the project can be recreated on another machine.

## Traceability

Each meaningful change should be committed with a clear commit message.

## Reliability

The project separates source files from generated build artifacts such as build, install, and log.

## Portability

Machine-specific files such as .DS_Store and editor folders are ignored.
